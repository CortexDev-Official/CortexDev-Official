Software developer and UI designer building Windows applications, web tools, and utilities for the Roblox desktop client.

## Projects

### [Goldstrap](https://goldstrap.app)

An open-source Roblox bootstrapper for Windows with FPS unlocking, custom fonts, and a FastFlag editor.

### [RXShade](https://rxshade.pages.dev)

Free, open-source real-time visual filters for the Roblox desktop client on Windows.

### [UNMARK](https://cortexdev.online/UNMARK/)

A browser-based tool that removes text watermarks associated with ChatGPT, Claude, and Gemini.
